## 1. 产品概述

租房对比助手是一款面向正在挑选合租房用户的纯前端工具，帮助用户系统化地记录、比较和筛选备选房源。用户可以在浏览器中直接录入房源信息、进行多维度对比、记录位置印象、打分评估，并导出看房清单和决策参考。

- **核心价值**：将零散的租房信息结构化，提供可视化对比和决策辅助，降低选房决策成本
- **目标用户**：正在寻找合租房的年轻上班族、学生群体
- **产品定位**：轻量级、纯前端、离线可用的租房决策工具

## 2. 核心功能

### 2.1 功能模块

1. **录入区**：房源基本信息录入表单，支持增删改操作
2. **对比表**：多维度房源对比表格，支持按不同指标排序
3. **地图备注**：位置印象记录，支持商圈/地铁/学校/医院等标签
4. **评分卡**：多维度评分系统，安全/性价比/便利度/舒适度打分
5. **导出区**：看房清单、问题清单、最终候选列表导出

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页面 | 录入区 | 填写地址、租金、押金、面积、房型、通勤时间、室友情况、可入住日期 |
| 主页面 | 对比表 | 按总成本、通勤、采光、噪音、设施、风险备注多维度排序对比 |
| 主页面 | 地图备注 | 文字描述 + 标签形式记录商圈、地铁、学校、医院等位置印象 |
| 主页面 | 评分卡 | 安全、性价比、便利度、居住舒适度四维打分，支持星评 |
| 主页面 | 导出区 | 生成看房清单、问题清单、最终候选列表，支持复制导出 |

## 3. 核心流程

用户从录入房源信息开始，逐步完善每个房源的详细数据，通过对比表和评分卡进行横向比较，使用地图备注记录周边环境印象，最终通过导出功能整理出看房计划和决策清单。

```mermaid

    C --> D["对比表排序分析"]
    D --> E["筛选候选房源"]
    E --> F["导出看房/问题清单"]
    F --> G["最终决策"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **设计方向**：现代简约 + 温暖宜居风格，传达家的舒适感
- **主色调**：温暖的橙棕色系（#E67E22）作为主色，搭配米白色背景
- **辅助色**：柔和的蓝绿色（#1ABC9C）用于强调和交互元素
- **字体**：标题使用「Noto Serif SC」衬线字体，正文使用「Noto Sans SC」无衬线字体，营造舒适阅读体验
- **卡片风格**：圆角卡片 + 柔和阴影 + 微悬浮动效
- **整体布局**：左右分栏布局，左侧为录入和操作区，右侧为对比和展示区

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 主页面 | 录入区 | 表单卡片、分组标签、输入框、下拉选择、日期选择器、添加/删除按钮 |
| 主页面 | 对比表 | 数据表格、排序箭头、高亮选中行、滚动容器、色阶指示 |
| 主页面 | 地图备注 | 标签云、彩色标签、文本域、标签分类图标 |
| 主页面 | 评分卡 | 星级评分组件、进度条展示、维度图标、总分汇总 |
| 主页面 | 导出区 | 选项卡切换、文本预览区、一键复制按钮、格式化输出 |

### 4.3 响应式

- 桌面端（>1024px）：左右双栏布局，信息密度适中
- 平板端（768-1024px）：上下堆叠布局，模块可折叠
- 移动端（<768px）：单列布局，简化表单，优化触控体验

### 4.4 动效与交互

- 卡片悬浮时轻微上浮 + 阴影加深
- 表单输入焦点态边框渐变动画
- 评分星级悬停预览效果
- 标签添加/删除的弹性动效
- 数据排序切换的平滑过渡
